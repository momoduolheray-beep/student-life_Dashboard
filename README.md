# Student Life Dashboard

## V2 Features
- Course tracker and Nigerian 5-point GPA calculator
- Assignment tracker with due dates and priority
- Mark assignments complete
- Overdue assignment indicator
- Weekly timetable with day, time and venue
- Browser local storage
- Light/dark mode
- Responsive mobile layout

## GPA Scale
A = 5, B = 4, C = 3, D = 2, E = 1, F = 0.
