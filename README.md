# Student Life Dashboard

Version 1 of the Student Life Dashboard.

## V1 Features

- Course tracker
- Course unit totals
- Nigerian 5-point GPA calculation
- A-F grade support
- Automatic GPA calculation
- Delete courses
- Local browser storage
- Light/dark mode
- Responsive mobile layout

## GPA Scale

| Grade | Point |
|---|---:|
| A | 5 |
| B | 4 |
| C | 3 |
| D | 2 |
| E | 1 |
| F | 0 |

## How to run

Open `index.html` in a web browser.

No server or database is required for V1.
